# common/ 可复用公共件

> 上级：[根 README](../README.md)

**既不认识 MCU，也不认识 RTOS** 的纯逻辑 / 数据结构组件，跨实验、跨框架复用。

## 规划内容

- fifo（环形缓冲）
- crc
- utils（位操作 / 对齐 / 字节序 / 断言）
- 协议解析（帧解析器）
- 日志 / CLI 的纯逻辑部分

## 边界

- 不得 include 任何 vendor 头文件
- 不得依赖具体外设（板级依赖下沉 `platform/`）
- 不得依赖 RTOS API（需要 RTOS 的适配放 `frameworks/<fw>/`）
- 设计思想与 PAL 平台抽象的分层思想呼应
