> 新建实验时：把本文件复制为 `experiments/0XX_topic/README.md` 并填写。
> 编号与 Level 约定见根目录 `ROADMAP.md`。
> “仪器验证步骤”和“故障注入”是必填项——四原则（可观察、可测量、可故障注入、可复现）落地的载体。
> 引脚、板载外设名称和连接关系必须以当前目标板的官方 User Manual / 原理图为准，不从其他型号开发板直接照搬。

## 仪器验证步骤

写清楚：

- 使用什么仪器（逻辑分析仪 / 万用表 / 示波器 / 串口等）。
- 仪器如何连接。
- 触发条件是什么。
- 预期波形 / 电平 / 周期 / 频率 / 数据内容是什么。
- 实际测量值是多少，与理论值是否一致。

精选实验依据存入本实验的 `artifacts/`，例如：

- 波形截图（PNG/JPG）
- 少量关键 CSV / TXT
- 串口日志
- 寄存器截图
- 结论性记录

体积较大的原始采样文件、仪器工程文件放入 `artifacts/raw/`；该目录由 `.gitignore` 忽略，不进入 Git。

## 故障注入

本实验主动制造什么故障，例如：

- 断线 / 接错引脚
- 有效电平判断错误
- 时钟配置错误
- GPIO 模式 / 上下拉 / 复用配置错误
- 中断未清标志 / 优先级错误
- DMA / 缓冲区配置错误

对每个故障记录：

1. 如何制造。
2. 预期现象。
3. 实际现象。
4. 如何用寄存器、调试器或仪器定位。
5. 如何恢复。

- 最终结论。
- 与预期不一致的原因。
